# InterviewIQ AI - Frontend Blueprint

## Project Goal

Build a premium, production-quality AI SaaS frontend for InterviewIQ AI.

The application should look like a real commercial product, suitable for a professional portfolio.

---

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS v4
- React Router
- Axios
- Lucide React
- React Icons
- Manrope Font

---

## Design Principles

The UI should feel:

- Professional
- Clean
- Modern
- Premium
- AI-powered
- Minimal

Avoid:

- Cartoon illustrations
- Fake statistics
- Glassmorphism everywhere
- Heavy gradients
- Cluttered layouts

## Component Rules

Everything must be reusable.

Never duplicate UI.

Use reusable:

- Button
- Input
- Card
- Badge
- Modal
- Avatar
- Navbar
- Sidebar

## Backend

The Django backend is already implemented.

Never modify backend code.

Only consume existing APIs.

---

## Coding Rules

Use functional components.

Use React hooks.

Keep components small.

Keep code readable.

Avoid unnecessary complexity.

---

## Development Workflow

Build one module at a time.

Review after every module.

Never generate the entire application in one step.
