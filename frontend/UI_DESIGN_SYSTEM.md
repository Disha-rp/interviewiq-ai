# InterviewIQ AI - UI Design System

## Design Philosophy

InterviewIQ AI is a premium AI SaaS platform.

The interface should feel:

- Modern
- Professional
- Intelligent
- Clean
- Trustworthy

Never childish.

Never cartoonish.

Never template-like.
